# LIMITLESS — Credit Finder

Responsive, interactive front-end demo for a card-linked offer discovery marketplace.

## Live demo
https://yashvijayvargiya1903.github.io/credit-finder-/ (available once GitHub Pages is enabled for the `main` branch).

## Run locally
Open `index.html` in a browser, or serve this repository with any static web server.

## Included
- Responsive landing page with offer search, filters and sorting
- 20 fictitious merchant offers across five fictional banks
- Customer, cardholder and simulated admin portals
- Simulated checkout with success/failure outcomes
- Demo offer listing submission and mock activity tables
- Privacy, terms and consent/deletion information panels

## Important
This is a static demonstration, not a production financial platform. No live offers, identity verification, authentication, database or financial transactions are connected. Never enter card numbers, CVV, PIN or OTP. The demo does not claim security certification or production readiness.

A production implementation requires a reviewed backend, real role-based authorization, secure sessions, database policies, provider-approved checkout/tokenisation and applicable legal/compliance review.
